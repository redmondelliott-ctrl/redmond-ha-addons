# Famz add-ons

Home Assistant add-ons used by Famz (a private family app).

- **Sainsbury's Connector**: keeps a Sainsbury's groceries session on your
  own Home Assistant machine so the family app can add favourites to the
  trolley. Unofficial; not affiliated with Sainsbury's. Your login is stored
  only in the add-on's configuration on your machine.

Source of truth lives in the private Home-App repo (`ha-addons/`); this repo
is a published copy.
